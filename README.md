# SWYNEX Bioinformatics Project

## Project Overview

This repository contains my work completed as part of the SWYNEX Bioinformatics Internship.

The project focuses on biological dataset selection, data cleaning, statistical analysis, data visualization, and interpretation using publicly available genomic data.

**Selected Dataset:** GSE10072 – Lung Adenocarcinoma Gene Expression

## Project Tasks

### Task 1 – Biological Dataset Selection

Selection and description of a publicly available biological dataset for computational analysis.

[View Task 1](https://github.com/naheedmomin/SWYNEX-Bioinformatics-Project/tree/main/Task-1-Biological-Dataset-Selection)

### Task 2 – Data Cleaning and Basic Analysis

Dataset inspection, data quality assessment, descriptive statistical analysis, and preliminary tumor vs non-tumor comparison using Python.

[View Task 2](https://github.com/naheedmomin/SWYNEX-Bioinformatics-Project/tree/main/Task-2-Data-Cleaning-and-Basic-Analysis)

### Task 3 – Visualization and Interpretation

Visualization and exploratory interpretation of gene expression data using Python.

The analysis includes:

- Histogram of gene expression values
- Overall expression distribution using a boxplot
- Sample-wise expression distribution
- Expression density distribution
- Sample-wise mean expression
- Tumor vs non-tumor mean expression comparison

The visualizations were used to explore expression distributions, sample variability, and differences in average expression patterns between tumor and non-tumor tissue groups.

[View Task 3](https://github.com/naheedmomin/SWYNEX-Bioinformatics-Project/tree/main/Task-3-Visualization-and-Interpretation)

### Task 4 – Final Bioinformatics Report

Preparation of a comprehensive bioinformatics report summarizing the dataset, research question, objectives, methodology, results, exploratory analysis, discussion, limitations, conclusion, and future directions.

The report integrates findings from the previous tasks and presents the analysis of the GSE10072 gene expression dataset in a structured scientific format.

[View Task 4 – Final Report](https://github.com/naheedmomin/SWYNEX-Bioinformatics-Project/tree/main/Task-4-Final-Bioinformatics-Report)
